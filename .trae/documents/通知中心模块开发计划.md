# 通知中心模块开发计划

## 需求概述

在 ccw88.com 项目中新建一个通知中心模块，用于：
1. 查看短信发送日志和验证码记录
2. 维护阿里云短信发信参数
3. 提供腾讯云短信插件配置的快捷链接
4. 清理历史数据

## 现有资源分析

### 当前项目 (ccw88.com) 已有
- **腾讯云短信插件**: `addons/qcloudsms/` - 已安装并配置
- **短信模型**: `application/common/model/Sms.php` - fa_sms 表
- **短信类**: `application/common/library/Sms.php` - 验证码发送/校验
- **短信表结构**: fa_sms (id, event, mobile, code, ip, createtime, times)

### 参考项目 (ccw99.com) 结构
- **控制器**: `app/admin/controller/SmsCenter.php`
- **视图**: `app/admin/view/sms_center/` (index.html, logs_search.html, otp_search.html)
- **阿里云短信配置**: `app/admin/view/config/sms.html`

## 开发计划

### 第一阶段：数据库准备

#### 1.1 创建短信发送日志表 `fa_sms_log`
```sql
CREATE TABLE `fa_sms_log` (
  `id` int(10) unsigned NOT NULL AUTO_INCREMENT,
  `phone` varchar(20) NOT NULL DEFAULT '' COMMENT '手机号',
  `template_code` varchar(64) DEFAULT '' COMMENT '短信模板Code',
  `scene` varchar(32) DEFAULT '' COMMENT '业务场景',
  `channel` varchar(32) DEFAULT 'qcloud' COMMENT '发送渠道(qcloud/aliyun)',
  `success` tinyint(1) DEFAULT 0 COMMENT '是否成功',
  `provider_biz_id` varchar(64) DEFAULT '' COMMENT '服务商回执ID',
  `request_payload` text COMMENT '请求参数',
  `error` varchar(500) DEFAULT '' COMMENT '错误信息',
  `createtime` bigint(16) DEFAULT NULL COMMENT '创建时间',
  PRIMARY KEY (`id`),
  KEY `idx_phone` (`phone`),
  KEY `idx_scene` (`scene`),
  KEY `idx_success` (`success`),
  KEY `idx_createtime` (`createtime`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='短信发送日志';
```

#### 1.2 扩展 fa_sms 表（如需要）
添加字段：type, info_id, expire_at, used_at 等

### 第二阶段：后台控制器

#### 2.1 创建控制器 `application/admin/controller/Notice.php`
- `index()` - 通知中心主页（Tab切换）
- `logs()` - 短信发送日志列表
- `otp()` - 验证码记录列表
- `cleanup()` - 清理历史数据
- `aliyun()` - 阿里云短信配置页
- `testAliyunSms()` - 测试阿里云短信发送

### 第三阶段：后台视图

#### 3.1 创建视图目录 `application/admin/view/notice/`
- `index.html` - 主页（Tab布局）
- `logs_search.html` - 日志搜索表单
- `otp_search.html` - 验证码搜索表单
- `aliyun.html` - 阿里云短信配置表单

### 第四阶段：阿里云短信服务

#### 4.1 创建阿里云短信服务类 `application/common/library/AliyunSms.php`
- 配置读取/保存
- 短信发送方法
- 测试发送方法

#### 4.2 添加阿里云短信配置项
在系统配置中添加：
- aliyun_sms_access_key_id
- aliyun_sms_access_key_secret
- aliyun_sms_sign_name
- aliyun_sms_region_id
- aliyun_sms_endpoint
