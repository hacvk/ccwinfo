# 修复游客发布验证成功后不跳转的问题

## 问题分析

在 `public/assets/frontend/js/info-publish-select.js` 的 `bindGuestVerify` 函数中：

```javascript
post(state.cfg.verifyGuestApi, {phone: phone, code: code}, function (res) {
    if (!isSuccess(res)) return showAlert(res.msg || '验证失败', 'danger');

    state.guestAccess = true;
    state.guestPhone = phone;
    $('#guest-verify-modal').modal('hide');
    showAlert(res.msg || '验证成功', 'success');
    setTimeout(goTarget, 120);  // 问题：延迟太短，且 showAlert 没有传递 duration
});
```

### 问题原因
1. `showAlert` 调用时没有传递 `duration` 参数
2. `setTimeout` 延迟只有 120ms，太短
3. 与之前修复的 `info-detail-auth.js` 存在相同的问题

## 修复方案

修改 `info-publish-select.js` 中的 `bindGuestVerify` 函数：

```javascript
post(state.cfg.verifyGuestApi, {phone: phone, code: code}, function (res) {
    if (!isSuccess(res)) return showAlert(res.msg || '验证失败', 'danger');

    state.guestAccess = true;
    state.guestPhone = phone;
    $('#guest-verify-modal').modal('hide');
    
    var redirectUrl = state.targetUrl || state.cfg.publishUrl || '/';
    showAlert(res.msg || '验证成功', 'success', 800);
    
    setTimeout(function () {
        window.location.href = toAbsoluteUrl(redirectUrl);
    }, 500);
});
```

## 需要修改的文件

1. `public/assets/frontend/js/info-publish-select.js` - 修复跳转逻辑
2. `application/index/view/info/publish_select.html` - 更新 JS 缓存参数

## 执行步骤

1. 修改 `info-publish-select.js` 中的 `bindGuestVerify` 函数
2. 更新模板中的 JS 引用，添加缓存破坏参数
