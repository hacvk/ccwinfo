# 用户中心推广申请功能规划

## 需求概述
在用户中心新增"申请推广"功能模块，包含：
1. 侧边栏新增"申请推广"入口菜单
2. 推广申请页面（复用现有申请功能）
3. 我的订单列表页面（查看自己的推广订单）

## 实施步骤

### 步骤1：修改侧边栏菜单
**文件**: `application/index/view/common/sidenav.html`

在"用户中心"菜单组中新增"申请推广"菜单项：
- 链接到推广申请页面
- 使用合适的图标

### 步骤2：创建用户中心推广订单列表页面
**新文件**: `application/index/view/user/promotion_orders.html`

功能：
- 显示当前登录用户的所有推广订单
- 展示订单信息：订单ID、推广位、标题、金额、支付状态、订单状态、创建时间
- 提供"申请新推广"按钮
- 提供"查看详情"操作

### 步骤3：在 User 控制器添加订单列表方法
**文件**: `application/index/controller/User.php`

新增 `promotionOrders()` 方法：
- 查询当前用户的 PromotionOrder 记录
- 关联查询 PromotionItem 和 PromotionSlot 信息
- 支持分页显示
- 赋值给视图

### 步骤4：添加路由（如需要）
**文件**: `application/index/route.php`（如存在）或检查现有路由配置

确保用户中心的推广订单页面可以通过 `/user/promotion_orders` 访问

## 关键代码参考

### 侧边栏菜单新增项
```html
<li class="list-group-item {:check_nav_active('user/promotionOrders')}">
    <a href="{:url('index/user/promotionOrders')}">
        <i class="fa fa-bullhorn fa-fw"></i> 申请推广
    </a>
</li>
```

### User 控制器新增方法
```php
public function promotionOrders()
{
    $user = $this->auth->getUser();
    $orders = \app\common\model\PromotionOrder::where('user_id', $user->id)
        ->order('id desc')
        ->paginate(10);
    
    $this->assign('orders', $orders);
    $this->assign('title', '我的推广订单');
    return $this->view->fetch('user/promotion_orders');
}
```

## 页面效果
- 用户登录后进入用户中心，侧边栏可见"申请推广"菜单
- 点击后进入订单列表页面，查看历史申请记录
- 点击"申请新推广"跳转到现有的 `/promotion/apply` 页面
- 订单列表显示支付状态和审核状态，方便用户跟踪进度
