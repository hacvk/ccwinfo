# 用户中心返工 + 公共布局迁移

## 问题根因

FastAdmin 前台使用 ThinkPHP 的 **layout 布局机制**（`Frontend.php` L55-57），而非模板继承：
- 控制器设置 `$layout = 'default'` -> 自动使用 `layout/default.html`
- 布局文件用 `{__CONTENT__}` 做内容占位
- 视图文件只写内容部分，**禁止使用** `{extend}` / `{block}`

源项目（ThinkAdmin）使用 `{extend}` + `{block}` 模板继承，两者机制完全不同。

## 步骤 2.0：迁移静态资源（基础依赖）

将源项目的前端静态资源复制到目标项目：

**源目录**: `D:\phpEnv\www\ccw99.com\public\static\frontend\`
**目标目录**: `d:\phpEnv\www\ccw88.com\public\assets\frontend\`

需要复制的资源：
- `frontend-theme-v1/css/style.css` (579行, 核心主题样式: header/navbar/footer/按钮/响应式)
- `frontend-theme-v1/images/logo.png` (站点 Logo)
- `frontend-theme-v1/images/inbanner.png` (头部 Banner)
- `css/frontend.css` (459行, 页面内容区通用样式)
- `images/` 目录 (如有前台用到的图片)

注意：源项目的 `bootstrap.min.css` 不复制，FastAdmin 自带 Bootstrap。

## 步骤 2.1：改造公共布局 layout/default.html

**文件**: `application/index/view/layout/default.html` (64行)

将 FastAdmin 默认的简单 navbar 替换为源项目的完整 header + navbar + footer 结构，保留 `{__CONTENT__}` 机制不变。

改造要点：
- `<head>` 中增加 `style.css` 和 `frontend.css` 引用
- 替换 `<nav>` 为源项目 header 结构（logo + banner + 搜索 + 账户）
- 添加蓝色导航栏（分类导航）
- 替换 `<footer>` 为源项目 footer 结构
- **变量适配**: 源项目用 `$currentUser`，FastAdmin 用 `$user`；源项目用 `$site_name`，FastAdmin 用 `$site.name`
- **路由适配**: 源项目用 `{:url('index/user/dashboard')}`，FastAdmin 用 `{:url('user/index')}`
- **模板标签**: 源项目用 `{volist name='list' id='vo'}`，FastAdmin 用 `{volist name="list" id="vo"}` (兼容)

导航栏分类数据暂用硬编码（与源项目一致），后续模块 3 开发时再改为动态加载。
